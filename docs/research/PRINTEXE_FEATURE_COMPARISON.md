"Existing PrintEXE" = verified by source inspection of this repository; references = verified from code (QZ, ZMA) or documentation (PaperCut, PrintNode) — see `PRINTEXE_COMPETITOR_RESEARCH.md` for confidence labels.

## Verdict per axis (what we change after this research)

1. **Keep** (already equal or better than references): durable queue with uncertain-outcome invariants; hybrid background model; offline-first design; update verification; DB encryption.
2. **Adopt**: QZ's trust/consent patterns where a local listener is ever added; PrintNode's state-event vocabulary + capability dictionary + idempotency keys; ZMA's printer resolution chain + status machine + capped history; PaperCut's diagnostics decision tree + log bundle.
3. **Fix** (gaps no reference excuses): spooler-outcome false positives; raw-GDI placeholder rendering; unwired log redactor; missing Diagnostics screen; stub tray actions; installer asset gaps; missing managed PDF inspection; approval gate.
4. **Reject**: secret-in-query auth (ZMA); revocation-disabled PKIX (QZ); fire-and-forget job handling (ZMA); synthetic spooler IDs (our own v0.4 bug — already removed); inventing backend endpoints the SaaS does not expose (contract rule).
